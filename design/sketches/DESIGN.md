# 临时设计基准（草稿专用 · 不是项目正式规范）

项目根目录原本没有 `DESIGN.md`。这份是 `design/sketches/` 的一次性基准，
`01/`、`02/`、`03/` 三个原型都从这里取颜色、字体、圆角和状态语义。

来源：上一轮视觉候选里的**第 2 个「像纸质词典一样暖」**（上一轮尚未选定编号，
这里按推荐值先写死；若最终选的是 1 或 3，整体换下面这张表即可，布局草稿不用改）。

- 真实产品色值：`awesome-design-md/references/claude.md`、`notion.md`
- 现成主题：`theme-factory/themes/golden-hour.md`
- 风格依据：`ui-ux-pro-max/data/styles.csv` 第 56 行 `E-Ink / Paper`（适合阅读类应用）

## 颜色

| 用途 | 值 | 说明 |
|---|---|---|
| 窗口底色 | `#f5f4ed` | 米白纸色，替代现在的冷白 `#f7f9fd` |
| 卡片 / 输入框 | `#faf9f5` | 象牙白，比底色亮一点点 |
| 主文字 | `#141413` | 暖黑，不用纯黑 |
| 次要文字 | `#5e5d59` | 只用这一档，避免上一轮诊断里「灰字太淡」 |
| 强调 / 主按钮 | `#c96442` | 陶土色，只用在能点的地方 |
| 边线 | `#e8e6dc` | 暖色细线 |
| 选中态浅底 | `#f0eee6` | 悬停、选中、气泡底 |

状态色（三个方向统一）：

| 状态 | 标记色 | 文案基调 |
|---|---|---|
| empty | `#5e5d59` | 告诉用户「下一步做什么」 |
| loading | `#c1666b` | 写清楚在等什么，不转圈了事 |
| error | `#b53333` | 说清原因 + 给可点的退路 |
| 超长内容 | `#5e5d59` | 能滚、能收起，不裁掉 |

## 字体

- 标题：`"Noto Serif CJK SC", "Songti SC", Georgia, serif`（宋体感）
- 正文 / 界面：`"Noto Sans CJK SC", "Microsoft YaHei", system-ui, sans-serif`
- 公式：沿用项目现有 `DejaVu Serif` 斜体，与宋体标题同族
- 全部系统字体，不下载网络字体（PySide6 离线可用）

正向尺度：标题 20px / 小标题 15px / 正文 15px / 辅助 13px，正文行距 1.6。
具体每档放大或缩小，由 `01/`、`02/`、`03/` 各自决定。

## 组件约定

- 圆角统一 10px，边线统一 1px `#e8e6dc`
- 卡片之间靠留白分组，不靠一堆描边
- 强调色一次只出现在一个地方（主按钮或选中项）

## 状态与真实内容（三个方向共用，禁止 Lorem ipsum）

- 页面：`初判` / `结果` / `设置·外观`
- 状态：`正常（基准）` + 必标的 `empty` / `loading` / `error` / `超长内容`
- 初判页三种真实内容：`NaCl`、`E=mc²`、一句中文长句
- 结果页含右对齐用户气泡、模型卡片、真实化学表格、追问气泡
- 外观页来自 `settings_dialog.py::_build_look`：结果卡片字号 9–28、深色主题、说明文字、确定/取消/应用

## 三个方向各自决定什么

本文件只管颜色、字体、圆角、状态语义；**布局立场归各目录**：

| 目录 | 立场 |
|---|---|
| `01/` | 更紧凑：一屏更多选项、行更矮、双列网格 |
| `02/` | 更宽松：单列大卡片、留白多、只突出少数推荐 |
| `03/` | 换结构：左侧固定分类导航 + 右侧内容区 |

## 第 2 轮约定（三份草稿统一）

- 顶栏一律用内联 SVG 线性图标（查询 / 搜索 / 新标签 / 图片识别 / 独立输入框 / 设置），不用文字按钮；鼠标悬停给文字说明。
- 不单独占一行显示窗口标题和页面名；状态标记并入底部那条细线。
- 「自定义」是点击后弹出的输入窗口，不是常驻输入框；结果页保留追问输入条。
- **只保留一个滚动容器**：条目变多时由内容区统一滚动，内层列表不再自己滚，避免双滚动条与滚轮行为不确定。
- 颜色、字体、圆角不变。

## 第 3 轮定稿（正式实现以此为准）

- 选中的布局方向：**02 更宽松多留白**（单列大卡片、字更大、留白更多、只一层滚动）。
- 顶栏只留 3 个图标：查询、搜索、新标签。图片识别 / 独立输入框 / 设置不进顶栏，
  走 `Ctrl+Alt+S` / `Ctrl+I` / `F3` 与托盘菜单（功能不删）。
- 窗口没有底部区域：返回 / 复制 / 关闭改由 `Alt+Left`、右键菜单、`Esc` 承担；
  「未发送网络请求」这类话只在预览或出错时作为结果卡片内一行小字出现。
- 颜色、字体、圆角不变，见上文颜色表与字体段。
- 正式实现把本文件的色值写成 `src/clipllm02/studio/theme_tokens.py` 的
  `LIGHT` / `DARK` 两套常量（组织方式参照 pyqt6-ui-designer 的 design_tokens.md）。

草稿是一次性的：选定方向后应把它转成正式实现，而不是继续维护这些 HTML。
