这一版改了什么

· 现代简洁：统一冷中性色阶（白表面 + 靛蓝强调），去掉暖纸底色与衬线标题，全站改无衬线；卡片柔和圆角 + 轻投影，输入框聚焦有蓝色描边光环，滚动条更细更干净。
· 常用查询方式 + 其他角度：两处都是恒定两列（任何窗口宽度都不变，也不出现 3 / 4 列），间距 4–8px 随宽度微调；主推荐 42px / 15px、其他角度 34px / 13px，靠字号行高与强调细条分主次。
· 组件质感：分段控件、悬停微抬、追问气泡改现代 IM 样式，表格加圆角包裹，按钮统一靛蓝主/灰次级；功能、页面与内容一项不减。
· 幂等自适应：外框内边距 / 圆角用 clamp() + cqi 连续跟随窗口宽度；@container 只调间距、不改列数；JS 只在档位变化时写一次 data-tier，档位不变不碰 DOM、不重建控件。
· 保留定稿：顶栏 3 个图标、无底部区域、暖纸色基调、三种真实内容、四种状态。
