# 方向 03 · 换结构（左侧分类导航）

## 立场

**别把「我在哪、还能去哪」藏进一个小抽屉。** 这个方向不调行高也不调留白，而是直接改结构：左侧常驻一列导航，右侧内容跟着切换，让类别、对话轮次、设置页签始终看得见。

## 具体做法

- **布局**：窗口分成 174px 左栏 + 右侧内容区。左栏在三个页面里换三种身份：初判页是「类别」（化学物质 / LaTeX 公式 / 中文 / 英语…），结果页是「对话轮次」（第 1 轮、两次追问…），外观页是「设置页签」（外观 / 拦截 / ① ② ③ / 搜索 / 模型 / 知识库 / 行为）。
- **字号**：沿用中间档（按钮 13px、标题 17px），不靠大小制造差异；差异全部来自结构。
- **颜色**：同一套 `../DESIGN.md`，选中项用陶土色实心块，明确「现在在这一类」。
- **交互**：左侧项可以点，选中态会跟着变；顶栏控制台照旧切页面 / 状态 / 真实内容；「查询」演示 loading → 正常。

## 做了哪些页面和状态

| 页面 | 左侧导航 | 四种状态 |
|---|---|---|
| 初判 | 类别列表 + 其他角度 + 知识库 | empty 引导；loading 骨架；error 拦截；超长内容 24 条真实方式 + 中文长句 |
| 结果 | 对话轮次列表 | empty 无结果；loading 骨架；error 超时；超长内容 3 轮追问 + 8 行表格 |
| 设置 · 外观 | 9 个真实设置页签（原来挤在顶部的一排） | empty / loading / error / 长说明与深浅预览四态齐全 |

所有文案都是真实内容，没有 Lorem ipsum。

## 取舍

- **强在**：类别多、页签多、多轮追问时不会迷路；直接回应上一轮诊断里「单标签自动隐藏页签」「类别收进一个『其他 ▾』小抽屉」「9 个页签挤成一排」的问题；设置页的页签竖排后，中文长标签不再挤。
- **弱在**：左栏固定占掉约 174px，结果表格和长公式更窄；窗口本来就是取词弹窗，加一栏会让「轻量小窗」的感觉变重；改动最大，要动布局容器而不是只改样式。
- **代价**：`QTabWidget` / 抽屉那套实现基本要重排；三个文件里的样式表仍然要统一，否则左栏和右栏会各说各话。

## 适合什么人

会频繁换类别、经常改提示词模板和查询方式、一次查询要追问好几轮的人；也就是把它当「小型知识工作台」而不是「弹一下就走的小卡片」的人。
