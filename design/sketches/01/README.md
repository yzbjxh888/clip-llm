# 方向 01 · 更紧凑

## 立场

**一屏看全，少滚动。** 假定用户每天要查几十次，最在意「选项全在眼前、鼠标不用走远」，所以把行高、字号、间距全部压紧，用双列网格把更多选项塞进同一个窗口。

## 具体做法

- **布局**：查询方式双列网格，其他角度也是双列；窗口固定 780 × 620，顶栏 30px 高，底部只留一条状态细线。
- **字号**：主按钮 12px、其他角度 11px、表格 11px；标题 15px，靠颜色而不是大小区分层级。
- **颜色**：完全照 `../DESIGN.md`（米白纸底 `#f5f4ed`、陶土色 `#c96442` 只用在主按钮和标题），不额外加色。
- **交互**：顶部控制台切页面 / 状态 / 真实内容；点窗口里的「查询」会进入 loading，约 1 秒后回到正常态；点任一查询方式跳到结果页；底部状态卡可直接点。

## 做了哪些页面和状态

| 页面 | 内容 | 四种状态 |
|---|---|---|
| 初判 | `NaCl`（化学物质 8 项）、`E=mc²`（LaTeX 公式 10 项）、中文长句（论述句，可滚动） | empty 引导语 + 三个真实示例；loading 显示「正在判断类别…」和骨架；error 是 URL 被拦截并给退路；超长内容铺 24 条真实查询方式且能滚 |
| 结果 | 右对齐用户气泡 + 模型卡片 + 真实化学表格 + 追问气泡 | empty 无结果引导；loading 骨架 + 「正在生成第 1 轮回答…」；error 接口超时并保留提示词；超长内容含 3 轮追问和 8 行表格 |
| 设置 · 外观 | 结果卡片字号 9–28、深色主题、确定 / 取消 / 应用 | empty 配置未载入；loading 读取 settings.json；error 字号 31 越界的校验提示；超长内容含长说明和深浅两套预览 |

所有文案都是真实内容，没有 Lorem ipsum。

## 取舍

- **强在**：选项多时扫得快；窗口小，悬浮在浏览器旁边不挡事；一屏能看到「初判 → 其他角度 → 自定义」全貌。
- **弱在**：长答案、宽表格挤在一起，读起来累；按钮矮，容易点错；上一轮诊断里说的「一屏白卡片没主次」这个毛病，这个方向并没有解决，只是把它排得更整齐。
- **代价最小**：几乎只改 CSS，Python 侧的网格列数逻辑基本能沿用。

## 适合什么人

高频查词、用键盘多于鼠标、窗口常年开在小尺寸笔记本上、希望「别让我滚动」的人。
