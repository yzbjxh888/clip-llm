# 方向 02 · 更宽松多留白

## 立场

**一次只专注几件事。** 假定用户是来「读一段解释」的，不是来挑按钮的，所以宁可滚动，也要把每一项做大、把周围留空，让眼睛有休息的地方。

## 具体做法

- **布局**：单列大卡片，卡片高 56px、内边距 14–18px；窗口内边距 28–36px；卡片之间 11px 空隙；窗口加高到 660px。
- **字号**：标题 23px、按钮 16px、表格 13px、回答正文 14px、行距放宽到 1.8；标题和正文一眼分得开。
- **颜色**：与 01 完全同一套 `../DESIGN.md` 值，**只靠间距和字号拉开差距**，方便单独比较布局，不被配色干扰。
- **交互**：与 01 相同的控制台和状态切换；「查询」同样演示 loading → 正常的状态转换；点查询方式跳结果页。

## 做了哪些页面和状态

| 页面 | 内容 | 四种状态 |
|---|---|---|
| 初判 | `NaCl`、`E=mc²`、中文长句三种真实内容；单列展示，超出部分滚动 | empty 大留白引导；loading 骨架更宽更高；error 拦截提示；超长内容 24 条真实方式 + 中文长句全文 |
| 结果 | 气泡、模型卡片、真实化学表格、追问 | empty 引导回初判；loading 六段骨架；error 超时提示；超长内容 3 轮追问 + 8 行表格 |
| 设置 · 外观 | 同样来自 `_build_look` 的真实控件 | empty / loading / error / 长说明与深浅预览四态齐全 |

所有文案都是真实内容，没有 Lorem ipsum。

## 取舍

- **强在**：长答案、表格、公式最好读；主次靠大小和留白自然形成，不用加一堆描边；顺手缓解上一轮诊断里「标题和按钮一样大」「字小、灰字淡」的毛病。
- **弱在**：一屏只能看到 4–5 个选项，选项多时要滚；窗口更大，悬浮时挡住更多桌面；高频查词的人会觉得「慢」。
- **代价**：字号、行距、内边距要整体调一遍；但布局仍是单列，结构性改动不大。

## 适合什么人

把结果当文章读的人、常在结果页多轮追问的人、用大屏或高分屏的人、以及希望软件「安静一点」的人。

## 第 2 轮修订（按反馈）

- **功能补齐**：顶栏恢复查询 / 网页搜索 / 新标签 / 图片识别 / 独立输入框 / 设置；「自定义」改成点击后弹出的输入窗口，不再常驻占地方；结果页恢复追问输入条与返回 / 复制 / 关闭；设置页保留 9 个页签和确定 / 取消 / 应用。
- **图标代替文字**：顶栏、底部操作、标题行右侧一律内联 SVG 线性图标，鼠标悬停有文字说明。
- **去掉那一栏**：删掉单独占一行的窗口标题 / 页面名状态栏，状态标记并入底部那条细线。
- **只留一层滚动**：内层列表不再自己滚，长内容统一由内容区滚动，避免条目变多时出现两条滚动条、滚轮不知道滚哪层。
- 颜色沿用 `../DESIGN.md`，一处未改。
